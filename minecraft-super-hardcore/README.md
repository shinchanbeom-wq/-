# Minecraft Super Hardcore Datapack (Java 1.21.11)

Minecraft Java Edition 1.21.11용 슈퍼 하드코어 데이터 팩입니다.

## 적용되는 규칙

- 난이도를 항상 `hard`로 유지합니다.
- 자연 회복을 활성화합니다. 단, 몸통 내구도가 낮거나 파괴되면 허기/약화 효과로 자연 치유력이 약해집니다.
- 인벤토리 보존을 비활성화합니다.
- 즉시 리스폰을 비활성화합니다.
- 기본 최대 체력은 6(하트 3칸)입니다.
- `하트의 정수`를 손에 들고 우클릭하면 최대 체력이 2씩 증가하며, 최대 40(하트 20칸)까지 늘릴 수 있습니다.
- `신체 메뉴`를 들고 Shift+우클릭하면 신체 상태, 하트 강화, 붕대 사용 창으로 이동하는 클릭형 메뉴가 열립니다.
- 플레이어가 한 번 사망하면 관전 모드로 전환됩니다.
- 인벤토리에 무거운 종류의 아이템이 있을수록 이동 속도가 느려집니다.
- 피해를 받으면 몸, 왼팔, 오른팔, 왼다리, 오른다리 내구도가 감소합니다.
- 팔 내구도가 낮으면 채굴 속도와 전투 능력이 감소하고, 왼팔 파괴 시 보조 손 아이템을 사용할 수 없습니다.
- 다리 내구도가 낮으면 이동 속도와 점프력이 감소하고, 파괴된 다리 한쪽당 큰 이동 속도 패널티를 받습니다.

## 조합법

### 하트의 정수

- 재료: 빨간색 염료 1개 + 금 조각 1개
- 사용: 하트의 정수를 손에 들고 우클릭
- 효과: 최대 체력 +2(하트 1칸), 최대 하트 20칸까지 가능

### 신체 메뉴

- 재료: 책 1개 + 빨간색 염료 1개
- 사용: 신체 메뉴를 손에 들고 Shift+우클릭
- 효과: 신체 상태, 하트 강화, 붕대 사용 창으로 이동하는 클릭형 메뉴 열기

### 붕대

- 재료: 양털 2개
- 사용: `/trigger 붕대사용`
- 효과: 모든 신체 부위 내구도 15 회복

## 명령어

- `/trigger 신체`: 몸, 왼팔, 오른팔, 왼다리, 오른다리 내구도 확인
- 하트의 정수 우클릭: 손에 든 하트의 정수를 1개 소모하여 최대 체력 증가
- 신체 메뉴 Shift+우클릭 또는 `/trigger 메뉴`: 클릭형 메뉴 열기
- `/trigger 붕대사용`: 인벤토리의 붕대를 1개 소모하여 신체 부위 내구도 회복

> Minecraft 데이터 팩은 `/신체`처럼 완전히 새로운 슬래시 명령어를 직접 추가할 수 없으므로, 보조 명령은 바닐라에서 지원하는 `/trigger 신체` 형태로 제공합니다.

## 강화된 엔티티

- 좀비: 스폰 시 최대 체력 3배, 이동 속도 1.2배, 문/목재/흙/조약돌 등 주변 블록 파괴 압박을 적용합니다.
- 스켈레톤: 화살을 쏠 때 추가 화살 14발을 생성해 총 15발 산탄형 공격을 합니다.
- 크리퍼: 이동 속도 1.8배, 폭발 반경 2배로 강화됩니다.
- 거미: 1.21 계열의 `minecraft:weaving`(방적) 효과를 직접 부여받고, 플레이어가 죽이면 좀벌레 5마리를 생성합니다.

## 설치 방법

1. 월드 폴더의 `datapacks` 폴더에 `minecraft-super-hardcore` 폴더를 복사합니다.
2. 월드에 접속한 뒤 `/reload`를 실행합니다.
3. `/datapack list`에서 `Super Hardcore`가 활성화되어 있는지 확인합니다.

## 파일 구조

```text
minecraft-super-hardcore/
├── pack.mcmeta
└── data/
    ├── minecraft/tags/function/{load,tick}.json
    └── superhardcore/
        ├── function/*.mcfunction
        ├── recipe/*.json
        └── tags/item/*.json
```

## 참고

Minecraft Java Edition 1.21.11의 데이터 팩 형식은 최신 `pack.mcmeta` 문법에 맞춰 `min_format`/`max_format`을 `[94, 1]`로 지정합니다.
